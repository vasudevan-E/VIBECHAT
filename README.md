# 💬 VibeChat

### Connect. Chat. Communicate.

VibeChat is a modern real-time messaging web application designed to make communication simple, fast, and seamless. Discover people, connect with them, and enjoy a smooth messaging experience through a clean and responsive interface.

## 🌐 Live Demo

🚀 **[Visit VibeChat](https://moonlit-message-room.vercel.app/)**

## ✨ Features

- 🔐 Secure User Authentication
- 👤 User Profiles
- 🔍 Search and Discover Users
- 💬 Real-Time Messaging
- 📱 Responsive User Interface
- 🛡️ Supabase Database Integration

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Supabase
- PostgreSQL
- Vercel

## 🎯 Project Vision

VibeChat aims to provide a simple, modern, and reliable communication platform with a focus on user experience, real-time interaction, and secure data management.
